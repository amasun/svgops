# svgops

svgops is a catalog for browsing functional website UI icons by product and purpose. It keeps the fast search, filtering, copy, source-link, and favorites workflow of SVGL while using a data model designed for interface icons.

## Current Catalog

- Website collections (Cursor, Trae, VS Code, Kimi, Monica)
- Over 1,807 functional icons
- Website and function filters with shareable URL parameters
- Persistent favorites
- Responsive desktop and mobile layouts
- Source links and component import copying

The starter functional icons are from [Lucide](https://lucide.dev/) under the ISC license. Website names and logos identify product context; the functional icon examples are not represented as official assets from those websites.

## Development

Requirements: Node.js 24 and pnpm.

```bash
pnpm install
pnpm dev
```

Production build:

```bash
pnpm build
```
